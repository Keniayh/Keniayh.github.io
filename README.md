Este sitio reúne mi perfil profesional, formación, experiencia, tecnologías, proyectos y medios de contacto en un solo lugar.

El portafolio está construido como un sitio web estático y cuenta con:

- 🌙 Tema claro y oscuro.
- 🌎 Cambio de idioma entre español e inglés.
- 📱 Diseño responsive.
- 💻 Sección de tecnologías y herramientas.
- 🧩 Experiencia y formación académica.
- 📂 Proyectos destacados enlazados a GitHub.
- 🧠 Mini-reto interactivo de programación.
- 📄 Descarga del CV.
- 🔗 Enlaces a GitHub, LinkedIn y correo electrónico.
- ✨ Animaciones y efectos de aparición al desplazarse.

## 🚀 Ejecutar localmente

Como es un sitio estático, no necesita un servidor backend para ejecutarse.

1. Clona el repositorio:

```bash
git clone https://github.com/Keniayh/Keniayh.github.io.git
```

2. Entra al proyecto:

```bash
cd Keniayh.github.io
```

3. Abre `index.html` en el navegador o utiliza una extensión como **Live Server** desde Visual Studio Code.
